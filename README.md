# 模写コーディング Noble Finance

## 概要
Figmaテンプレートを元に制作した、コーポレートサイトの模写コーディングです。  
デザインを忠実に再現しつつ、構造と可読性を意識して実装しました。

figma テンプレートURL：
https://www.figma.com/community/file/1498084903136440786

## 使用技術
- HTML
- CSS
- JavaScript

## 目的
- デザインカンプの再現
- レスポンシブ設計力の向上

## 工夫した点
- header / main / section / footer を使用し、分かりやすいページの構成を意識
- BEM命名規則でクラス名を設計
- booking.html ページで、mainのコンテンツ量が画面全体の高さに足りない場合でも footer を下部に表示
- testimonial の部分では、クリックで表示内容が変わるようにJavaScriptを使用
